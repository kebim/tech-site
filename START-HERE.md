# Start Here — Tech GitHub Pages Package

1. Upload **all files in this folder** to the root of a new GitHub repository.
2. Set the repository’s Pages source to **GitHub Actions**.
3. Add `LEARN_SITE_URL` and `TECH_SITE_URL` under **Settings → Secrets and variables → Actions → Variables**.
4. Wait for the **Deploy Tech to GitHub Pages** workflow to finish, then configure the Tech custom domain in **Settings → Pages**.

See `README.md` and the main project guide for the full DNS steps.
